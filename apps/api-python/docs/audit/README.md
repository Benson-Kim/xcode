# Audit reports

One file per run, never edited afterwards (a later run writes a new file):
- `docs/prompts/verify.md` writes `<yyyy-mm-dd>-verify-<scope>.md`;
- prompt 11 (`docs/prompts/11-audit.md`, the final run over everything) writes
  `<yyyy-mm-dd>-conversion-audit.md`;
- a design session (the D0 of prompts 07b and 08b) writes `<yyyy-mm-dd>-design-<prompt>-d0.md`
  with its challenge pass; it is the author's own record, not a verification.

A phase counts as validated only with a report here (`docs/00-principles.md` section 11).
A verifier reads earlier reports only after finishing its own pass.
