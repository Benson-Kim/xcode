# tests.support

Shared fixtures: `database.py` (template database, per-test clone, `executor_connection` for statements as `xcode_api_executor` under RLS), `rows.py` (one organization with a row in every table, inserted as the owner, for schema tests), `permission_catalogue.json` (the catalogue table of `inventory-http-contract.md` section 3.2 with the role defaults; read by `tests/db/test_enum_parity.py` and `tests/unit/test_permission_keys.py`), `clock.py` (`ManualClock`), `mail.py` (`MailSpy`), `fakes.py` (`FakeOpsRepository`, `FakeIdentityRepository`, `FakeTenancyRepository` with `FakeMember`, and `FakeSetupRepository`, which shares the organization, members and change log of a `FakeTenancyRepository`; complete against their Protocols; the auth port doubles `PinHasherSpy`, `CodeMailerSpy`, `FixedSecrets`), `auth_cases.py`, `tenancy_cases.py` and `setup_cases.py` (the scenario tables run against the fakes and the routines by `tests/db/test_fakes_match_routines.py`), `phone_vectors.py` (the phone table shared by `PhoneNumber.parse` and `identity.normalize_phone`), `pins.py` (`HasherAtCapacity`, a PIN hasher whose pool is full, for the tests that a full hasher stops a request before any decision), `scenario.py` (accounts provisioned through `api.ops_provision_user`, the `Auth` caller of the `api.auth_*` routines as `xcode_app`, and the row helpers the routine tests adjust state with as the owner), `tenancy.py` (members, companies, vehicles, scopes and change-log rows for the tenancy routine tests, plus the people routine callers and refusal checks), `setup_rows.py` (targets, away periods, catalogue rows, scheduled items with their versions and shares, investment entries and revenue records inserted as the owner, the `api.setup_*` callers, and the report scenario `seed_report_fleet`); the gateway statement counter is the `statement_counter` fixture in `tests/conftest.py`.

HTTP: `client.py` (`AuthApi`: an httpx client on the real app that provisions a person and sets the first PIN through the setup flow, so tests get real tokens; the `make_api` fixture in `tests/api/conftest.py` builds it) and `setup_client.py` (`join(api, email=, phone=, role=)` gives a `Member` with bearer headers; `ok`, `problem`, `empty` and `statements` check the `/setup` answers and the statement budget).

`fakes.py`: in-memory implementations of every port and repository Protocol for use-case
unit tests; the contract cases they must satisfy are shared with
`tests/db/test_fakes_match_routines.py`, which runs them against the real routines too.
